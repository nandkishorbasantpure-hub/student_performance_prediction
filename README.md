# Student Performance Prediction

## 📌 Project Overview
This project predicts student academic performance based on factors such as
study hours, attendance, and previous scores using Machine Learning techniques.

The objective is to understand how data can be used in education systems
(schools and colleges) to analyze and improve student outcomes.

---

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning (Supervised Learning)
